Developer Mode Installation

⚠️ Developer Mode Notice

This guide is for developers who want to load the extension directly from source. If you're not a developer, we recommend installing from the Chrome Web Store instead.

Download Options

Choose the appropriate version based on your browser:

  • MV2 Version (For Brave Browser): Download MV2
    • Supports basic authentication
    • Works on Brave browser
    • Not compatible with latest Chrome versions
  • MV3 Version (For Chrome): Download MV3
    • Compatible with latest Chrome versions
    • Does not support basic authentication
    • Recommended for Chrome users

Installation Instructions for Chrome

  1. Open Chrome and navigate to chrome://extensions
  2. Enable "Developer mode" using the toggle switch in the top right corner
  3. Download the MV3 version (autologin-mv3.zip)
  4. Extract the downloaded ZIP file to a folder
  5. Click "Load unpacked" and select the extracted folder
  6. The extension should now appear in your extensions list

Installation Instructions for Brave

  1. Open Brave and navigate to brave://extensions
  2. Enable "Developer mode" using the toggle switch in the top right corner
  3. Download the MV2 version (autologin-mv2.zip)
  4. Extract the downloaded ZIP file to a folder
  5. Click "Load unpacked" and select the extracted folder
  6. The extension should now appear in your extensions list

Troubleshooting

  • Make sure you're using the correct version for your browser (MV2 for Brave, MV3 for Chrome)
  • Ensure all files are properly extracted from the ZIP file
  • Check the browser's console for any error messages
  • If you encounter issues, try reloading the extension
